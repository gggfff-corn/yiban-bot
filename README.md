# 易班助手 YibanBot

Windows 桌面端易班自动化工具：自动登录（含验证码）、签到、点赞、发帖、评论，支持多账号、无人值守。

> 本项目仅供个人学习自动化技术与自用，请遵守易班平台用户协议。使用自动化脚本可能导致账号被限流或封禁，风险自负；请勿用于商业用途或批量刷量。

---

## 功能

| 功能 | 说明 |
|---|---|
| 自动登录 | 支持网易易盾文字点选 / 数美空间推理 / 短信验证码，验证码本地识别 |
| 签到 | 按账号批量执行 |
| 点赞 | 可设置数量上限 |
| 发帖 | 标题自动生成去重，撞标题自动「返回修改」换标题重发；正文从文案库随机组合 |
| 评论 | 自动打开帖子、输入内容、提交；触发风控自动冷却重试 |
| 多账号 | 多线程并发，独立浏览器 profile，互不干扰 |
| 计时 | 登录、签到、点赞、发帖、评论、总耗时逐个输出，方便评估效率 |

## 安装

1. 把 `YibanBot_1.2.13.zip` 解压到任意目录（**不要**放在 C 盘根目录或含中文/空格的路径下）。
2. 把 `YibanBot_OCR_Patch_1.2.5.zip` 解压到 `YibanBot.exe` 所在的那一层，提示「目标已存在文件」时选择**替换**。
3. 双击 `YibanBot.exe`。首次运行会自动准备 Edge 驱动（约 12 MB，走国内镜像）。

安装完成后的目录结构：

```
YibanBot\
├─ YibanBot.exe
├─ _internal\              （运行库，勿删）
├─ runtime\
│  ├─ python\              （嵌入式 Python，主包自带）
│  └─ site-packages\       （OCR 补丁解压到这里，含 numpy / ddddocr / onnxruntime）
├─ drivers\                （首次运行自动生成）
├─ accounts.json           （首次运行自动生成，保存你的账号）
└─ config.json             （首次运行自动生成，保存程序配置）
```

程序包本身**不包含任何账号信息**，首次运行会生成空白配置，需要自己填账号。

### 关于数美验证码（可选补装）

- 网易易盾点选：装完 OCR 补丁即可用，无需其他操作。
- 数美「空间推理」：发帖第 4 条、评论第 4~5 条左右会开始弹。它需要 PaddleOCR 运行时（约 190 MB 依赖 + 230 MB 模型），请在程序里点状态栏旁的**【安装/修复】**，会自动测速选最快镜像下载，通常 2~5 分钟；中途关掉也不会白下，下次从断点继续。
- 只有精简补丁（没有 paddle）时，启动日志会提示「精简运行时：易盾可用，数美不可用」，此时数美验证码无法自动识别。

## 常见问题

**Q：首次启动或登录很慢？**
浏览器启动和页面加载都很快（1~5 秒）。旧版本曾经有两处空等：加载 PaddleOCR 模型（约 18 秒）和固定的登录状态检查（约 13 秒），1.2.3 起已改为按需加载，不再预等。

**Q：登录时弹出「需要验证您的身份」要我输短信验证码？**
这是新设备登录的正常风控。程序会自动点「获取验证码」，注意：点这个按钮本身还会再弹一次易盾点选，程序会先自动过掉它，按钮变成倒计时（如 `57s`）才说明短信真的发出去了。没收到的话，在弹窗里直接点【确定】留空，程序会自动重发。

**Q：提示「获取验证码」点了没反应 / 一直等？**
1.2.9 起修掉了：短信弹窗有淡入动画，动画中途点击会打偏且不报错；现在点击前会等按钮位置稳定，点完 4 秒没动静立即重试。

**Q：首次运行卡在「检查/更新驱动」？**
驱动下载已改为国内镜像优先（npmmirror），12 MB 约 2 秒。只有 Edge 主版本变化时才会重新下载，平时都是毫秒级跳过。

**Q：杀毒软件报毒 / SmartScreen 拦截？**
PyInstaller 打包的未签名程序常有误报，添加信任即可。介意的话可以自己看源码构建。

**Q：程序会不会把我的账号上传？**
不会。账号保存在本地 `accounts.json`，发布包里不含任何账号或凭据；网络请求只发往易班站点和（可选的）更新检查接口。

**Q：点了「停止」但任务还在跑？**
停止是在任务边界生效的，当前这一条（如正在识别验证码）会先走完，之后立即退出。

## version.json 结构

客户端更新检查和网站的下载页都读这个文件，发新版本时只需替换它，程序源码无需改动（版本号在构建时自动注入 exe）。

```json
{
  "version": "1.2.13",
  "date": "2026-11-26",
  "notes": "1.2.13 更新（多行文本，客户端弹窗和网页都直接展示）",
  "files": [
    {
      "role": "main",
      "name": "主程序 YibanBot v1.2.13",
      "filename": "YibanBot_1.2.13.zip",
      "desc": "Windows 桌面端，解压即用",
      "size": "124 MB"
    },
    {
      "role": "ocr",
      "name": "OCR 验证码识别补丁（1.2.5 起通用）",
      "filename": "YibanBot_OCR_Patch_1.2.5.zip",
      "desc": "必装（仅首次）",
      "size": "106 MB"
    }
  ]
}
```

字段说明：

- `version`：语义化版本号。客户端拿它和自己的版本比较，大于自己就提示更新。
- `date`：发布日期，网页展示用。
- `notes`：更新说明，支持 `\n` 换行。
- `files[]`：下载列表。`role` 仅作标识（`main` / `ocr`），`filename` 必须与服务器上的实际文件名一致。
- 没有 `url` 字段：客户端「打开下载页」固定跳 `https://smart-study.cn/downloads/`，避免发版时漏改。

## 目录与技术说明

- 打包：PyInstaller（`yiban/yiban_bot.spec`），本仓库构建产物为 `dist_app\YibanBot_*`。
- 自动化：Selenium + Edge（自带驱动管理，运行时自动匹配版本）。
- 验证码：
  - 网易易盾文字点选：ddddocr 检字块 + 多角度旋转识别 + 双识别器投票 + 唯一分配/排除法。
  - 数美空间推理：PaddleOCR 读题干（颜色+形状）+ OpenCV 分割取目标几何体。
- OCR 运行时不在主包内，按需安装到 `runtime\site-packages`，避免每次都下载 800 MB。
